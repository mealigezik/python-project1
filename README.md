# Python Projects

A collection of Python practice exercises and small experiments.

## Scope

This repository is a learning workspace for exploring Python fundamentals and building programming habits.

## Run

Open the relevant `.py` file and run it with Python 3:

```bash
python filename.py
```

Replace `filename.py` with the script you want to execute.

## Status

Learning repository. Individual exercises may be incomplete and are not presented as production-ready software.
